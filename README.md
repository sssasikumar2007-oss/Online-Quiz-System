# QuizPoint — Online Quiz System Website

## Features
- Responsive homepage and quiz category cards
- Three quiz topics: Programming Basics, Database & SQL, Computer Fundamentals
- 15 multiple-choice questions
- Instant score and percentage calculation
- Answer review with explanations
- Retry or select another quiz

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Select a quiz and answer the questions.

## Files
- `index.html`: page structure
- `style.css`: styling and responsive layout
- `script.js`: quiz questions, scoring, and results

This is a front-end demo; results are not saved to a database. A backend such as PHP/Node.js with MySQL is needed for persistent users and scores.
